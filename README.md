# shared-docs
Blogger・note・Facebook記事の共有資料

記事で紹介・参照している資料（仕様書、ロードマップ、ルート情報、旅程など）をまとめて公開するリポジトリです。

## カテゴリ

| カテゴリ | 内容 |
|---|---|
| `claude/` | Claudeで開発したプロジェクトの仕様書・ロードマップ |
| `cycling/` | サイクリング記事のルート・装備・記録などの資料 |
| `travel/` | 旅行記事の旅程・スポット情報などの資料 |
